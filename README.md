# Secure Testing Website

A professional full-stack web application designed for testing frontend-to-backend communication, API endpoints, error handling, and security boundaries.

## Features
- **Frontend Dashboard**: Responsive modern UI with request history and status indicators.
- **Backend API**: Endpoints for health checks, data retrieval, echo validation, and token authorization.
- **Security Protections**: Rate-limiting, input validation, strict static file serving (restricting access to private code), and environment variable protection.
- **Automated Tests**: Built-in test suite using Node.js test runner.
